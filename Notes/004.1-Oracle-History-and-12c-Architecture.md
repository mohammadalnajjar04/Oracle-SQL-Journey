# 004.1 - Oracle History and 12c Architecture

## Oracle History

### Oracle Founding

- Oracle was founded in 1977.
- Founders:
  - Larry Ellison
  - Bob Miner
  - Ed Oates

### Major Oracle Releases

| Version | Feature |
|----------|----------|
| Oracle V2 (1979) | First commercial SQL-based RDBMS |
| Oracle 3 (1983) | Written in C language |
| Oracle 4 | Read Consistency |
| Oracle 5 | Client/Server Computing |
| Oracle 6 | Introduced PL/SQL |
| Oracle 7 | Stored Procedures and Triggers |
| Oracle 8 | Object-Relational Features |
| Oracle 8i | Internet Features and Java Support |
| Oracle 9i | RAC and XML DB |
| Oracle 10g | Grid Computing |
| Oracle 11g | Improved Performance and Automation |
| Oracle 12c | Cloud and Multitenant Architecture |

### Main Features

- Cloud Ready Database

## Oracle 12c Architecture

### CDB (Container Database)

Main database container.

Example:

```sql
ORCL
```

Contains multiple PDBs.

### PDB (Pluggable Database)

Independent databases inside a CDB.

Examples:

- HR
- SALES
- FINANCE

Each PDB can have:

- Its own users
- Its own tables
- Its own applications

---

## Before Oracle 12c

Each application required:

- Separate database
- Separate server
- Separate administration

Problems:

- High cost
- More resources
- More maintenance

---

## Oracle 12c Multitenant Model

One CDB contains multiple PDBs.

Benefits:

- Easier administration
- Lower cost
- Better scalability
- Better resource sharing

---

## Key Takeaways

- Oracle was founded in 1977.
- Oracle V2 was the first commercial SQL database.
- Oracle 6 introduced PL/SQL.
- Oracle 10g introduced Grid Computing.
- Oracle 12c introduced Multitenant Architecture.
- Oracle 12c uses CDB and PDB architecture.
- Multiple databases can run inside one container database.
