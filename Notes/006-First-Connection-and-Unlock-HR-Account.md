# 006 - First Connection and Unlock HR Account

## Topics Covered

- Introduction to Oracle Database connections.
- Understanding database users.
- SYS account.
- SYSTEM account.
- HR sample schema.
- Unlocking user accounts.
- Creating the first database connection.

## Important Notes

### SYS User
- Administrative account.
- Has the highest privileges in Oracle Database.

### SYSTEM User
- Administrative account used for database management tasks.

### HR Schema
- Sample schema provided by Oracle.
- Contains sample tables used for learning SQL.

### First Connection
Required information:
- Username
- Password
- Host
- Port
- Service Name

## Key Takeaways

- Learned the difference between SYS and SYSTEM users.
- Learned the purpose of the HR schema.
- Understood the components required to create a database connection.
