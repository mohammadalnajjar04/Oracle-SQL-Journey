## System Development Life Cycle (SDLC)

### 1. Strategy and Analysis

* Analyze business requirements.
* Identify system objectives and user needs.

### 2. Design

* Design the database structure.
* Plan tables, relationships, and system architecture.

### 3. Build and Document

* Create tables and database objects.
* Develop and document the system.

### 4. Transition

* Move the system to testing and production environments.
* Verify that everything works correctly.

### 5. Production

* Deploy the system for end users.
* Maintain and improve the system over time.

## Database Fundamentals

### Data

Raw facts and information that can be stored and processed.

### Database

An organized collection of related data.

### DBMS

Database Management System used to store, retrieve, manage, and modify data.

### RDBMS

Relational Database Management System that stores data in related tables.

### ORDBMS

Object-Relational Database Management System that combines relational databases with object-oriented features.

---

## Table

* The basic storage unit in a relational database.
* Data is organized into rows and columns.
* Each row represents a record.
* Each column represents an attribute.

---

## Data Model & ERM

### Entity

A real-world object that can be identified.

Examples:

* Employee
* Student
* Department

### Attribute

A property that describes an entity.

Examples:

* Name
* Age
* Salary

### Relationship

A connection between two or more entities.

Examples:

* Employee works in Department.
* Student enrolls in Course.
