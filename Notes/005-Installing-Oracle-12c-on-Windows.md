# 005 - Installing Oracle 12c on Windows

## Topics Covered

- Oracle Database Versions
- Standard Edition vs Enterprise Edition
- Downloading Oracle Database
- Oracle Installation Process
- Container Database (CDB)
- Pluggable Database (PDB)

---

## Notes

- The course uses Oracle Database 12c.
- Oracle provides different editions for different use cases.
- During installation, a Container Database (CDB) can contain multiple Pluggable Databases (PDBs).
- Modern Oracle versions may have different installation steps.

---

## Key Takeaways

- Learned the different Oracle database editions.
- Understood the Oracle installation workflow.
- Learned the concepts of CDB and PDB.
